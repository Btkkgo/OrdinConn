## 公开交互摘要 — 持久化 macOS GitHub Sync

- **时间：** 2026-09-20（Asia/Shanghai）
- **阶段：** GitHub Public Sync 系统级调度修复
- **GitHub Issue：** [#2 — Establish Public Development Logging and GitHub Source of Truth](https://github.com/Btkkgo/OrdinConn/issues/2)
- **用户目标：** 让两小时 Public GitHub Sync 独立于 Codex/ChatGPT 运行，同时保留 Documentation-only Security Boundary。
- **Codex 检查内容：** 旧 Plist、Installer、Sync Allowlist、Credential Helper、launchd State、Structured Log、macOS TCC Event 与准确 Background Process Attribution。
- **Codex 变更内容：** 把 Runner/Working Directory 移到 Application Support；增加专用 Ad-hoc-signed `OrdinConn GitHub Sync` Launcher；保留仓库内 Fail-closed Sync Logic；增加明确 Tool Path、Structured Status Field、5 MiB Log Rotation 与 Installer Test；X Publication 继续在 Automation 外。
- **变更文件：** macOS GitHub Sync Installer/Uninstaller、Runner/Plist Template、Dedicated Launcher Source/Metadata、Test、Current Status、Build in Public 文档、Issue Record 与本 DevLog。
- **发现的问题：** 只移动 Shell Script 不够。TCC Log 证明 `/bin/bash` 仍是 Responsible Process，并被拒绝访问 `Documents`。已安装 Command Line Tools SDK 在 macOS 27 上也无法 Link，因此 Installer 必须明确选择 Active Full-Xcode Compiler 与 SDK。
- **解决方案：** 给窄范围 OrdinConn Launcher 独立 macOS Privacy Identity；Shell Runner 保持在 `Documents` 外；由 Launcher Spawn Runner。不向 Terminal 或 `/bin/bash` 授予广泛权限。使用 Git `osxkeychain` Credential Helper，不把 Token 放入 Plist、Runner 或 Repository。
- **执行的命令与测试：** Shell Syntax；Installer Rendering/Compile/Uninstall Test；Allowlisted Sync Integration Test；Sanitizer/Public-repository Security Test；Public Document Validation；`plutil`；`codesign`；`launchctl bootstrap/print/kickstart`；TCC Log Inspection；Remote Commit Verification 与第二次 No-change Run。
- **结果：** 主要 Scheduler 为 `com.ordinconn.github-sync`，登录时及每 7,200 秒运行，不依赖 Codex。Structured Log 记录 Repository、Branch、Scan、Changes、Commit、Push、Error 与 Status，不含 Credential。最终真实 Change/Push 与 No-change Evidence 已发布到 Issue #2。
- **剩余风险：** Launcher 使用本地 Ad-hoc Signature，重新安装或替换 Binary 后可能需再次授权 macOS Documents Permission。Product Runtime 与 Mobile M1.5 未改变。
- **建议下一步：** 保持 LaunchAgent 为主要方式；除非作为 Recovery Fallback，否则保持 Codex Heartbeat 暂停。
- **Codex 工程笔记：** macOS Privacy Attribution 跟随 Responsible Executable，而不只是 Shell Script 位置；窄范围 Identity 比向 General-purpose Interpreter 授予广泛权限更安全、可靠。
