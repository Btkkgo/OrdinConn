# Mobile Intelligence UI

## Navigation

The left rail contains only the application icon and three destinations: Home, Warehouse, and Settings. The main surface is predominantly black with restrained purple ambience and yellow reserved for selection, status, and primary actions.

## Home

Home is a linked three-column workspace:

1. Intelligence Feed lists API, WebSocket, RSS, HTML, browser, desktop, and mobile items with source, account/channel, summary, time, type, evidence status, assets, confidence, and favorite state.
2. Mobile Live View shows device/session state, current app/activity, task, runtime state, the latest frame, and semantic element overlays.
3. Related Signals prioritizes signals related to the selected feed item. If none exists, it shows evidence and strategy readiness instead of inventing a signal.

Selecting a feed item opens Data Detail with source content, observation/evidence lineage, discussion, research, related-signal, favorite, tagging, and warehouse actions.

## Warehouse

Warehouse is a user-facing research library, not a database console. It supports search and filters for source, time, market, asset, type, app, evidence quality, favorite state, signal linkage, contradiction state, and official-source state. Saved entries retain references to their source object and associated evidence, signals, tasks, tags, notes, and collection.

## Settings

Settings groups Model, Strategy, Language, Text Size, and Mobile Runtime. Text scaling supports 90%, 100%, 110%, and 120%, applies immediately, persists, and does not scale the phone frame.
