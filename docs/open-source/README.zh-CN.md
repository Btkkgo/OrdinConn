## 状态用语

- **已实现（Implemented）**：行为存在于当前仓库中。
- **已验证（Verified）**：命名检查已在明确的 Revision 或环境中成功运行。
- **已设计（Designed）**：方向已记录，但尚不是已实现能力。
- **受阻（Blocked）**：必要的外部条件或 Acceptance Gate 尚未通过。

这些词不能互换使用。
