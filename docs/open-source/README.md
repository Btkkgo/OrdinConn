## Status language

- **Implemented** means the behavior exists in the current repository.
- **Verified** means a named check has run successfully against the stated revision or environment.
- **Designed** means the direction is documented but is not yet an implemented capability.
- **Blocked** means a required external condition or acceptance gate has not passed.

These words are deliberately not interchangeable.
